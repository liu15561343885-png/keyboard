## 原生布局核对

通过 iOS 18.6 Simulator 的系统中文键盘 Accessibility 层级核对：

```text
QWERTY 26 键:
  q..p / a..l / shift z..m delete
  底部 123, emoji, space, return
  第二行左右缩进约 19.3pt

九键:
  123  ，  ABC  DEF  ⌫
  #+=  GHI JKL  MNO  标点
  中   PQRS TUV WXYZ 换行(跨2行)
  。   标点 空格(跨2列)
```

工程按该网格实现；原生九键的 emoji/颜文字/选拼音键因“UI 不使用 emoji”被替换为标点/。，位置保持不变。

## 已知风险

- 九键采用原生 5 列 4 行网格（含跨行 Return、跨列 Space），但 288pt 高度下视觉仍需真机确认。
- T9 对极短数字序列候选有限。
- 候选展开按钮真实点击未做 UI 测试。
- 玻璃效果通过运行时 `UIGlassEffect` 实现；当前用 iOS 18 SDK 编译，旧 SDK 无编译期类型检查。
- 免费签名通常不包含 App Groups，主 App 与键盘可能无法共享设置/词频。
